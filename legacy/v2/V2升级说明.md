# Agent Range V2 · 升级与交付说明

## 版本内容

此包基于仓库提交 `663ec54048b3af5b56d80ff37fbaf2ed3984e433` 改造，包含安全控制面、四个确定性模拟场景、安全/漏洞对照、事件时间线、Dify/Coze 适配与自动化测试。四个场景均使用虚构数据，不代表真实模型或真实 RAG 的安全结论。

可选真实模型实验默认关闭，仅用于只读问题，不执行工具；它已通过本地伪服务测试，但**尚未与真实模型服务商进行端到端验证**。

## 升级已有仓库

1. 先备份代码、配置和运行数据；不要把真实密钥或私人信息提交进 Git。
2. 将本包的 `agent-range-v2/` 内容合并到你的项目根目录。保留原项目的 `.git/`；不要将 ZIP 内文件放在额外一层目录中。
3. 旧版 `data/state.json` 不再作为运行状态。V2 使用默认被忽略的 `.agent-range/`，**旧数据不会自动迁移**。如需旧数据，请在隔离环境审查并按业务需要迁移；先备份。
4. 如果原仓库已跟踪 `data/state.json`，仅添加 `.gitignore` 不会取消跟踪；确认已备份且不应继续提交运行状态后，可执行：

   ```bash
   git rm --cached --ignore-unmatch data/state.json
   ```

   此命令只取消 Git 跟踪，不删除工作区文件；请自行检查旧文件是否含敏感内容并按策略保管或删除。
5. 控制 API 现在需要独立的 `AGENT_RANGE_CONTROL_TOKEN`；旧的匿名控制 API 客户端需更新。Dify `admin/admin` 模拟登录默认关闭，只有显式设置 `AGENT_RANGE_DEMO_LOGIN=1` 才启用，**不要在公网启用**。
6. 本地运行以下测试并检查 Git 变更，再由你自行推送。

```bash
python3 -m unittest discover -s tests -v
git status --short
```

## 本地启动

```bash
# 在可信本机终端生成独立的随机控制令牌
export AGENT_RANGE_CONTROL_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"
python3 server.py
```

访问 `http://127.0.0.1:8787/labs`，点击“设置控制令牌”，输入该环境变量的值。原接口控制台仍位于 `/`。完整接口、场景及可选模型配置见 `README.md`。

## 验证记录与安全限制

- `python3 -m unittest discover -s tests -v`：24 项通过（包括控制面、跨平台令牌、模拟场景、SSE 和本地伪模型服务）。
- 四个场景的桌面交互和移动端布局已通过浏览器检查；GitHub Actions 的配置随包提供，但尚未在你的 GitHub 仓库实际运行。
- 默认仅监听本机，演示令牌为公开固定值；控制台当前是单一共享管理令牌，而非完整多用户身份系统。**不要将这个教学原型直接暴露公网，也不要存入生产密钥或真实用户数据。**
- 如需公网/多人服务，应先补齐独立身份认证、TLS、网络隔离、分布式限流、审计和真正多租户隔离。
